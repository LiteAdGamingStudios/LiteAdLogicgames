# LiteAd Logic Games

LiteAd Logic Games is a Flutter-based game hub containing lightweight logic and board games within a single application.

## Planned games

* Memory Match
* Dots and Boxes
* Connect Four
* Block Puzzle

Additional games may be added through future updates after development, testing and app-size review.

## Getting started

**Before cloning, modifying or contributing to this project, read [Start_Here.md](Start_Here.md).**

`Start_Here.md` explains:

* How to clone and configure the project
* Required Flutter and Android Studio setup
* Standard folder structure
* Branching and Git workflow
* Commit and Pull Request process
* Files that must never be uploaded
* Team development rules

## Project principles

* Lightweight and responsive
* No intrusive advertisements
* Simple, child- and family-friendly navigation
* Clear free and premium boundaries
* No unnecessary registration or questionnaires
* Modular structure for multiple developers
* Stable `main` branch with feature-based development
* Existing working functionality must not be changed without an explicit requirement

## Technology

* Flutter
* Dart
* Android Studio
* Git and GitHub
* Google Play services where required

## Development workflow

All development must follow:

```text
Pull latest main
→ Create a feature branch
→ Develop
→ Test
→ Commit
→ Push the feature branch
→ Create a Pull Request
→ Review
→ Merge into main
```

AI tools and contributors must read [AI_CONTEXT.md](AI_CONTEXT.md) before proposing or making changes.
